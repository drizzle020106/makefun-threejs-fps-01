A round-based tactical FPS (Counter-Strike-style, original map/art/names) — single-player vs bots, rounds, economy, buy menu, objectives. Playable offline in desktop Chrome from static files.
## Run it
```sh
node main.ts
```
Then open http://localhost:8124/ in desktop Chrome, click DEPLOY, and play. (Or `npx serve game`.)
